# 用量指标

桌面输入框下方、TUI 底栏和 `/session` 显示同一份 Core 统计。非交互文本模式在任务结束后将摘要写入 stderr，不改变模型回复的 stdout，也不向 JSON 事件流插入文本。

## 统计口径

缓存命中率按当前活动分支累计 token 数计算：

```text
缓存读取 /（未缓存输入 + 缓存读取 + 缓存写入）× 100%
```

不是对每次请求的百分比取平均值。输出不进入分母，推理 token 是输出的子集，不重复计算。缓存命中仍占上下文容量。

没有输入用量，或分支中有成功请求缺失用量／缓存统计时，命中率显示 `—`，不能沿用更早请求的比例。供应商明确报告零命中时显示 `0%`。旧记录没有缓存报告标记时，正的缓存读取量仍可使用；零值按未知处理，不重写历史。失败或中止且没有消耗报告的请求，不使已有统计变为未知。

上下文容量使用当前模型的窗口大小。已用量采用当前有效上下文中最近一次有效请求的总用量（输入含缓存，加输出），再估算后续消息。没有可用计量时，估算当前消息、系统提示词和工具定义；包含图片的粗略估算和应用消息转换，不包含被排除的手动命令输出。

估算值带 `≈`、`~` 或“约”。它不是模型端的精确分词结果，也不是整个会话的累计用量。压缩、切换模型或修改提示词／工具配置后，不沿用旧请求的计量锚点；直到下一次有效请求，使用当前上下文的估算。窗口未知时不显示百分比；超过容量时保留真实百分比，只将进度条限制到 100%。70% 和 90% 分别显示容量预警。

计量锚点还必须匹配本次运行实际观察到的请求配置：模型与接口、系统提示词、工具定义、推理设置及联网／权限策略。每次请求独立冻结指纹，临时记忆加入或移除后也重新校验；切换分支不会使旧计量重新获得信任。指纹只附在运行中的响应对象上，不写入 JSONL、桌面快照或日志，也不包含凭据。恢复记录无法证明配置一致时，先估算当前上下文，直到新请求返回可匹配的计量；历史累计用量与费用仍保留。

输入、输出及费用是当前活动分支累计值。费用按模型价目估算，不是供应商账单，也不包含未上报的费用。

## 数据更新

`AgentSession.get_stats().metrics` 是双端唯一计算来源。桌面工作区和 `session.snapshot` 返回完整 stats；消息结束、工具回合结束、压缩、模型或联网开关变化时通过 `session.statsChanged {stats}` 更新，不逐 token 重算。会话切换应用新快照，旧会话事件不能覆盖当前指标。

桌面 `/session` 只刷新当前会话的统计并追加本轮通知，不重建时间线；已有 `/help` 等本地输出保持可见。切换期间或切换后的旧快照、旧错误不能写入新会话。

TUI 底栏复用最近一次统计快照，普通重绘和流式增量不遍历历史。已有会话事件在消息入账、工具回合结束、压缩和 Plan 状态变化后使快照失效；切换分支、会话或模型、清空上下文、Shell 直通及回合结束后的临时提示词清理也会触发刷新。新增会改变统计的 TUI 操作时，应复用 `_refresh_footer()`，或在对应会话事件中使快照失效。

新用量记录包含可选 `cache_read_reported`，区分供应商未报告缓存与明确报告零命中。旧 JSONL 仍可读取，未改动 Plan reducer、工具审批或执行策略。

## 桌面用量分析

底栏的“用量分析”打开当前会话的分析抽屉。概览显示累计输入、输出、缓存命中率和估算费用，并单独显示当前上下文容量；趋势可切换每次模型请求的 Token 用量和费用，请求明细默认按请求顺序倒序分页，最新请求在前，趋势图保留原有先后顺序。明细包含模型、时间、状态及已报告的统计。一条用户消息可能触发多次模型请求。

抽屉通过只读 `session.usage({sessionId})` 获取 `{sessionId, leafId, stats, requests}`。`stats` 沿用 Core 的统计口径，`requests` 只投影当前活动分支的 assistant 记录，包括压缩前请求、模型切换和失败或中止的请求，不返回消息正文、工具参数或图片。过期会话 ID 返回 `STALE_SESSION`；Plan、归档及任务执行期间均可查看。

请求中的未知用量为 `null`，图表保留缺口，表格显示 `—`；明确报告的零值仍显示零。缓存统计不完整时不绘制构成图；费用取已保存的估算值，不调用供应商账单接口。只展示当前上下文容量，不从累计用量伪造历史上下文曲线，也不新增采样或持久化格式。

首次打开立即用已有会话快照显示指标、上下文容量和骨架内容。Ant Design 抽屉与 ECharts 图形分别按需加载；概览、请求明细和关闭操作不等待图表模块，图表加载失败也可单独重试。正常重开复用已加载的抽屉组件，关闭后停止查询并释放图表实例。打开期间沿用已有统计事件刷新，不逐 token 请求或轮询；会话切换会关闭抽屉，迟到响应不能覆盖新会话。加载失败可重试，关闭后焦点回到入口。

抽屉覆盖工具栏时暂停原生浏览器的显示和终端自动聚焦，关闭后恢复原网页、标签和终端状态。
